## Source and license boundaries

The repo's [original HTML followup](2026-11-10-original-html-link-and-hardware-audit.md) preserves all **131 user URLs** and 200 ideas. This pass opened specific implementation files from RIO and Pololu and inspected current CAD provenance. It did **not** review every destination for reuse fitness. The URL preservation test is not a compatibility or license clearance test. Existing Pololu VL53L0X driver is pinned by the version 1.3.1 commit recorded in `code/toolchain-lock.json`; do not replace it with the historical VL53L4CD library or treat different carrier logic as interchangeable. RIO is Arduino and Gemini Live; our current head is ESP-IDF/Xiaozhi, so transplant only the playback reference/delay calibration algorithms rather than its entire runtime. Bluino's CC BY and the SMARS NC SA material must never be relicensed as one MIT project.

## Key acceptance truth

CI source build and host tests are software evidence only. No actual WROOM board or XIAO microphone was flashed in this pass; no servo, charger, battery or finished robot was wired or tested. **PR stays draft and physical release stays HOLD.** The default `esp32_full` profile sets `DESK_ROBOT_STEPPER_HARDWARE_CUTOFF_QUALIFIED=0`; `esp32_dc_full` sets `DESK_ROBOT_DC_HARDWARE_CUTOFF_QUALIFIED=0`. Neither constitutes physical motion approval. The existing WROOM five floor/front safety guard, watchdog, owner-approved calibration and operator permit remain necessary, not sufficient, for physical motor permission. The extra three range fields are not a clearance certificate. The complete robot scope remains the goal.
