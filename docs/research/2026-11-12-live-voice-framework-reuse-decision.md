# Live voice framework reuse decision (2026-11-12)

## Scope and existing evidence
This is a research and integration decision for PR #17, not a claim of implemented acoustic full duplex. Read alongside `docs/guides/audio-barge-in.md`, `docs/guides/live-conversation.md`, and `docs/guides/sense-aec-port.md`. The existing architecture already has a Xiaozhi Sense audio path, a Mac generation-aware cancellation controller, an authenticated `/interrupt` route and device TTS stop/flush signaling. The documented missing gate is a real synchronized mic plus post-volume speaker reference for the Sense AFE, followed by measurable human double talk, DMA flush and actual playback acknowledgement. A new voice framework does not solve these device-side problems by itself.

## Smallest integration experiment for the implementation and QA tasks
1. Inspect current Sense `NoAudioCodecSimplexPdm` capture and I2S write paths and `AfeAudioEngine` MR input contract at pinned Xiaozhi revision. Identify exactly where post-gain PCM can be tapped without losing actual accepted playback timing.
2. Add a bounded, Sense-only playback reference adapter behind an opt-in configuration, retaining the existing working baseline. Keep capture and playback generations, frame counts and underflow diagnostics. Never represent a mono mic buffer as two-channel mic/reference samples.
3. Write host-testable reference resampling and interleaving cases: 24 kHz to 16 kHz chunk boundaries, partial writes, underflow, ring wrap, reset during output, obsolete generations and no reference after canceled audio. Do not hold a lock across blocking I2S operations.
4. Build the Sense firmware and inspect ESP-SR device AEC enablement, RAM and 8 MB partition constraints. A successful build is not an acoustic test.
5. Only on actual hardware measure playback echo suppression, double talk preservation, human interruption onset to speaker silence, flush acknowledgement, false self-interruptions and retained user transcripts, with camera, WiFi and motors active. Apply the preexisting 19/20 within 500 ms acceptance gate; report failures explicitly.

## Coordination and licensing
Keep PR #17 canonical; do not create a parallel voice rewrite or close existing work. This note is intended for implementation and independent QA to share via repository docs. No upstream source code was copied. Repository README license labels are preliminary evidence only; verify pinned upstream LICENSE and any bundled DSP model licenses before copying code. Source references and conclusions were researched on November 12, 2026. No firmware compilation, audio tests or physical qualification occurred in this research iteration.
