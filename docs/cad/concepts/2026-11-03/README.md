[rounded-head layout](../2026-11-03-rounded/README.md) is the current proposal.

mounts, OLED/lens and sensors are illustrative envelopes, not print files. The
unidentified power bank is not fitted. No manufacturing or physical-fit claim.

depth74mm and height48.8mm. Reading74mm as face width would be an orientation error.
