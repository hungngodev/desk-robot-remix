Unmodified SG90-variant exports: `Head.stl` about 47.9×53.1×14.6 source units and
`Hat.stl` about 47.9×53.1×5. Those are their exported orientations, not a finished
head assembly envelope. The source uses a 0.91-inch Waveshare display and head
servo; it does not establish our0.96-inch display, Sense/camera and audio fit.
