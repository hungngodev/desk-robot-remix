```text
Work through your assigned guide on draft PR #17. Your assignment continues after each finding, review reply, commit, and test run.
Start by reading your last checkpoint, checking the current PR head, and looking for overlapping work. For each actionable requirement, claim a small change, inspect the existing implementation, fix the gap, verify it through the normal entry point, and commit and push within your granted permissions. Resolve related review comments with evidence. Then immediately take the next unclaimed item in your guide.
If CI is pending, work on another independent item and return to the result. If another push supersedes your CI run, record which commit was canceled and which commit still needs verification. If hardware, access, or a peer change blocks one item, record exactly what would unblock it and continue with everything else you can do. Keep software, CI, and physical evidence separate.
After each item, update your existing checkpoint with the commit, verification result, open blockers, and the exact next action. On resumption, start there and recheck only what changed.
Before sending a final reply, scan every open requirement and related review comment in your guide. If you can take a concrete next action now, take it in this run. End voluntarily only when your scope is verified, every remaining item has a specific external blocker, or the user tells you to stop. Draft PR #17
```
