# Launch all 192 cards in short Chat runs

Open the [complete batch runbook](batches.md). It holds **Batch 01 plus all later batches** and every exact prompt. Start with the ten prompts in [Batch 01](batch-01.md). The book has 16 digital batches, 6 conditional operator-evidence batches, and the seven original verified or deferred dispositions.

**You launch every chat yourself.** Paste one exact box into one fresh Chat-mode chat and let the worker end after its result. Keep at most ten active chats. Then take the next eligible boxes directly from the same book. If a prerequisite is still open, fill the slot with an independent eligible card from a later batch.

A cap of ten active chats lets you use multiple batches. A cap of ten total launches gives you ten small checks. GitHub issues or tagged PR comments carry evidence from one finished chat to the next.
