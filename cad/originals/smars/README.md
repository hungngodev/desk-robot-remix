[source.json](source.json) records original public downloads, hashes, file sizes,
triangle counts and coordinate bounds. The four binary STL lengths and ZIP
integrity were checked; assembly-document contents have not yet been reviewed.
Do not mix these screwless chassis/wheel pieces with the screwed variants.
Follow the original assembly documents for print quantities and orientation;
one source file does not imply printing one copy.

STL has no unit metadata. Check millimeters against the dimensioned motors and
original assembly before slicing. These are collected source files, not a
verified print plate. No topology repair, slicing, tolerance test, head/gripper
clearance test or geometry change has been performed. Preserve noncommercial,
attribution and share-alike terms on any derivative of this geometry.

The ZIP includes macOS metadata. Keep this original archive intact; if extracting
documents, skip `__MACOSX` and `.DS_Store` entries.
