# Desk Robot Remix

An experimental SMARS companion robot combining an existing lift/gripper,
CoreS3 Lite head, ESP32-WROOM-32 body controller and laptop AI.

Start with [the accepted plan](PLAN.md). Implementation is in progress.
The $100–140 parts estimate is **before shipping/tax**; the first-build cap is $150.
No hardware performance is claimed until physical tests have been recorded.
